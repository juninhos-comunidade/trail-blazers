InterviewTrail
Style Guide · v1.0

A linguagem visual da trilha de preparação.

O sistema de design do InterviewTrail: cores, tipografia, componentes e voz. Feito para equilibrar credibilidade técnica e acolhimento — porque o produto existe para reduzir a insegurança de quem está começando, não para intimidar.

Projeto: InterviewTrail Equipe: Trail Blazers Stack: React + NestJS
01

Marca & personalidade

A metáfora central é a trilha: preparar-se para uma entrevista é uma jornada com marcos, e a cada etapa o candidato ganha clareza. Duas forças guiam cada decisão de interface.

Acolhedor

O público é dev júnior, muitas vezes ansioso. A interface tranquiliza: sem julgamento, sem jargão desnecessário, sempre indicando o próximo passo.

Técnico e preciso

Feito por e para quem programa. Monospace para código, badges de tecnologia, dados reais. Credibilidade se constrói no detalhe.

Orientado a progresso

Tudo comunica avanço. A trilha de etapas, os indicadores de aderência e as notas mostram evolução, não veredito.

07

Voz & texto

As palavras são material de design. Voz ativa, sem floreio, no tom da interface — nunca no da pessoa. Erros não pedem desculpa e nunca são vagos; telas vazias são um convite para agir.

✓ Faça

Botão de ação diz o que acontece:
"Iniciar entrevista"

Estado vazio convida:
"Sua trilha começa aqui. Crie sua primeira entrevista."

Erro é específico e aponta a saída:
"Não foi possível ler seus repositórios. Tente novamente em instantes."

✕ Evite

Rótulo genérico do sistema:
"Enviar"

Vazio sem direção:
"Nenhum dado encontrado."

Erro que se desculpa e não explica:
"Ops! Algo deu errado :("

08

Tokens para o código

Ponto de partida das CSS custom properties. Defina no :root e sobrescreva as superfícies por tema. Os componentes React devem consumir estes tokens, nunca hex soltos.

/* Cor de marca e accent */ --trail-500: #12B886; /* primária / sucesso */ --ember-400: #F5A623; /* accent / progresso */ /* Superfícies — tema escuro (padrão) */ --bg: #0C111A; --surface: #141B26; --border: #26303F; --text: #EDF1F5; --text-2: #8695A8; /* Superfícies — tema claro */ --bg: #F6F8FA; --surface: #FFFFFF; --border: #DCE3EB; --text: #141B26; --text-2: #45516A; /* Tipografia */ --font-display: 'Space Grotesk'; --font-body: 'Inter'; --font-mono: 'JetBrains Mono'; /* Base 4 · raios */ --sp-4: 16px; --r-md: 10px; --r-lg: 14px;
